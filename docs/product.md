# opendio 产品定义

## 一句话

opendio 是一个私人 AI 电台应用：它知道你现在适合听什么，并用 DJ 的方式把音乐播出来。

## 不是什么

opendio 不是：

- 普通歌单播放器
- 随机播放工具
- 只会根据关键词搜歌的聊天机器人
- 单纯套一个漂亮 UI 的音乐页

## 是什么

opendio 是：

- Personal AI Radio Agent
- AI DJ
- 场景化音乐助手
- 能长期学习用户 taste 的私人电台

## 核心体验

用户打开 opendio，不一定要自己选歌。

它应该先理解：

- 现在几点
- 用户是在工作、写代码、休息、出门、深夜放空，还是需要提神
- 用户最近喜欢/讨厌什么
- 当前天气、日程、上下文是否影响音乐选择

然后它输出：

1. 一段很短、自然、不打扰的 DJ 旁白。
2. 一首或一组适合当下的歌。
3. 必要时解释为什么放这首。
4. 播放后记住用户反馈。

## 关键原则

### 1. 不要像客服机器人

DJ 文案要自然、轻、有音乐感。不要模板腔，不要“根据您的需求，为您推荐”。

### 2. 少打扰

私人电台不是话痨。大多数时候音乐比话重要。

### 3. 先听懂场景，再选歌

选歌逻辑不应该只看关键词，而要结合时间、习惯、心情和历史反馈。

### 4. UI 先克制

视觉参考 Claudio FM，先追求 1:1 复原，不自行发散设计。

### 5. 音乐源优先接真实音乐库

Apple preview 只能用于 MVP。正式方向应接网易云 CLI 和用户自己的歌单。
